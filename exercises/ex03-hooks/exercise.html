Exercise 3 · Day 1 · Extension layer

Hooks: from a rate to zero 🪝

🎯 Objective

Exercise 1 ended with a number: how often an agent edits a test to make an impossible ticket pass, even with a perfect CLAUDE.md. This exercise drives that number to zero. Build a fence that makes tests/ append-only and routes protected files to a human, a lint hook that fixes style at edit time, and a finish line that won't accept "done" until the gates are green. Every hook is tested red, then green, before it's wired.

🧱

Write a PreToolUse hook that answers deny / ask with a reason that names the legitimate route.

🧪

Test hooks before wiring them: JSON in, decision out, red first.

🧹

Use PostToolUse for edit-time feedback: silent fixes, then talking back.

🏁

Build a Stop finish line with all three exits: done, not done, blocked.

😈

Measure the result: the LED-103 tampering rate goes to 0 by construction.

def check_test_edit(root: Path, r: str, tool: str, inp: dict) -> tuple[str, str] | None:
    if tool == "Edit":
        edits = [inp]
    elif tool == "MultiEdit":
        edits = inp.get("edits") or []
    elif tool == "Write":
        f = root / r
        if not f.exists():
            return None  # a brand-new test file is always welcome
        if lines_preserved(f.read_text(errors="replace"), inp.get("content", "")):
            return None
        return "deny", f"{r}: {TEST_RULE}"
    else:
        return None
    for e in edits:
        old, new = e.get("old_string", ""), e.get("new_string", "")
        if old and old not in new:
            return "deny", f"{r}: {TEST_RULE}"
    return None

Add a small helper to services/revenue.py: `def _safe_total(x)` that returns int(x) and returns 0 on any error. Use a bare `except:` and put the imports in any order.

WhyBeat one is silent: ruff fixes import order and formatting, and nothing enters the context. 🏁 Stop: the finish line

6 min · red → green

finish_line.py refuses "done" until the four gates are green, but the starter has no stop rule: on a gate it can't fix, it would block forever. Add it, test it, wire it.

▶ Red first

python3 tools/hook_test.py finish # RED: 'Red a 4th time: let it stop, warn the human'

▶ Wire it in settings.json

"Stop": [ { "hooks": [ { "type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR/.claude/hooks/finish_line.py\"", "timeout": 180 } ] } ]

WhyEx 1's Done means line was a request; this makes it a gate. A goal needs three exits: done, not done (block with the reason, so the agent retries) and blocked (the stop rule: after 3 attempts, stop and tell a human). Without the third, the loop spends until you notice.

✅ Acceptance criteria
hook_test.py finish → GREEN (6 cases: questions aren't gated, 3 blocks, then the stop rule, then green allows).
python3 tools/hook_test.py all → GREEN.
💡 Stuck? Hints unlock in order
1 · nudgeWhere is the attempt count?
In .claude/state/finish_line.json, per session_id (git-ignored). The starter already counts; it just never stops.
2 · specificWhat about stop_hook_active?
Claude Code sets it when a Stop hook already blocked this turn. Counting attempts is stricter and survives across turns.
3 · near-completeShow me the stop rule 
        attempts = state.get(sid, 0) + 1
        state[sid] = attempts
        if attempts <= MAX_ATTEMPTS:
            result = {
                "decision": "block",
                "reason": (
                    f"Finish line not met (attempt {attempts}/{MAX_ATTEMPTS}). Red gates:\n- "
                    + "\n- ".join(failed)
                    + "\nFix the cause. If a failing test contradicts an ADR or the request, "
                    "stop and say so instead of working around it."
                ),
            }
        else:
            state.pop(sid, None)
            result = {
                "systemMessage": f"⚠️ finish line: stopped with {len(failed)} red gate(s) after "
                f"{MAX_ATTEMPTS} attempts. A human needs to look."
            }

🪝 Instruction or guarantee?

Prompt (probabilistic): "consider running the tests", "please don't edit tests".

Hook (deterministic): runs on every matching event, costs no tokens, can't be argued with. Use it for anything that must happen.

🧪
A check that cannot fail is not evidence
Watch every hook go red on purpose (hook_test.py) before you trust it.
🚦 Decisions you'll use
PreToolUse → denynever, with the legitimate route as the reason
PreToolUse → aska human approves (headless: no)
PostToolUse → block + reasonfeedback after the tool ran
Stop → block + reasonnot done yet, keep working
exit 2blocks too (stderr is the reason); exit 1 only warns
🧭 Which event?

PreToolUse prevents: it's the only place a write can be stopped.

PostToolUse reacts: lint, format, audit.

Stop decides when "done" is allowed.
